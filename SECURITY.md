# Security policy

## Supported version

Only the latest commit on `main` is supported.

## Reporting a vulnerability

Please use this repository's **Security** tab to submit a private vulnerability report. Do not disclose a suspected vulnerability in a public issue.

Include:

- the affected file or behavior
- reproducible steps using synthetic data
- expected and observed results
- potential impact

Do not include customer data, credentials, live infrastructure details, or active exploit material.

## Scope

The showcase performs local, deterministic text analysis and has no production integrations. Reports concerning systems or components that are not present in this public repository are out of scope.
